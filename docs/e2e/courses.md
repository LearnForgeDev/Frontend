# Курсы

Источники: [хуки курсов](../../src/Services/Courses/hooks), [endpoint-модуль](../../src/Endpoints/courses/courses.endpoints.ts), [экран курса](../../src/Services/Courses/components/CourseWorkspace/CourseWorkspace.tsx), [валидация](../../src/Services/Courses/validation/courseValidation.ts), [требования к backend](../backend-contract-requirements.md).

Предусловия: backend с актуальными контрактами курсов; Teacher/Owner с реальным `canManage` курса; два ученика, группа учеников; несколько серверных уроков с содержимым. Текущий закреплённый CI-backend и базовый seed не доказывают готовность всех этих контрактов. До подготовки окружения сценарии не считать пройденными.

## Каталог и создание

| ID | Приоритет | Подготовка и действия | Ожидаемый результат |
| --- | --- | --- | --- |
| COURSE-01 | P0 | Каждой ролью открыть «Курсы» с доступными и недоступными этому пользователю курсами | Показаны только доступные курсы и корректное число уроков; у управляющего доступно создание, у ученика — его прогресс |
| COURSE-02 | P1 | Поиск по части названия/описания, другим регистром и с внешними пробелами; очистить; повторить в пустой школе | Найдены ожидаемые курсы; «нет результатов» отличается от отсутствия курсов; очистка восстанавливает список |
| COURSE-03 | P0 | Создать курс: название, описание, два урока, выбранный доступ; дождаться завершения всех запросов | Открыт реальный курс; metadata, порядок уроков и аудитория подтверждены API и после reload; на промежуточном этапе курс не открыт лишним ученикам |
| COURSE-04 | P1 | Отправить пустое название, превышение `COURSE_TITLE_MAX_LENGTH`/`COURSE_DESCRIPTION_MAX_LENGTH`, затем исправить; отменить создание | Невалидный курс не создаётся; есть понятная ошибка; отмена не создаёт сущность. Точные границы брать из `courseValidation.const.ts` |

## Программа, аудитория и прогресс

| ID | Приоритет | Подготовка и действия | Ожидаемый результат |
| --- | --- | --- | --- |
| COURSE-05 | P0 | Открыть «Настройки» существующего курса, изменить название и описание, сохранить | Изменения видны в каталоге и детали после reload; курс сохраняет public ID |
| COURSE-06 | P0 | Добавить урок, удалить другой из программы, поменять порядок стрелками; сохранить и reload | Программа соответствует выбранному порядку без дубликатов; удалённый из программы урок остаётся в школе |
| COURSE-07 | P0 | Проверить отдельными тестами доступ всей школе, выбранным ученикам и через группу | Назначенный ученик видит курс; неназначенный не получает его даже по прямому URL; roster отражает личное/групповое/школьное назначение |
| COURSE-08 | P0 | Сузить доступ существующего курса, удалив ученика/группу; в независимом контексте перечитать курс | Backend сохраняет новую аудиторию, отозванный доступ не раскрывает программу и прогресс. Проверять также после ранее прогретого кеша |
| COURSE-09 | P0 | Учеником открыть урок курса по строке программы; перейти обратно | Открыта `/courses/C/lessons/L`, загружено настоящее содержимое выбранного серверного урока; редактор readonly, возврат ведёт в тот же курс |
| COURSE-10 | P1 | Открыть ID урока, отсутствующего в программе, недоступный курс, несуществующий курс и урок с ошибкой чтения | Отображается недоступность/ошибка, нет чужого документа; «Повторить» после восстановления перечитывает нужный ресурс |
| COURSE-11 | P0 | Учеником отметить урок выполненным, reload; снять отметку, reload | Прогресс записан на backend и меняется в обе стороны; процент и число завершённых уроков пересчитаны, другой ученик не получает эту отметку |
| COURSE-12 | P1 | Управляющим открыть «Ученики», учеником — «Прогресс»; отдельно проверить курс без уроков/без назначенных учеников | Roster и прогресс соответствуют backend; при нуле обязательных элементов нет NaN/деления на ноль; ученик не видит чужую таблицу прогресса |
| COURSE-13 | P0 | Открыть удаление, отменить; затем подтвердить | Отмена сохраняет курс; подтверждение удаляет курс и его прогресс, возвращает в каталог; исходные уроки школы остаются |
| COURSE-14 | P1 | Вызвать ошибку списка/курса/roster/progress; повторить доступное чтение; отдельно отказ отметки прогресса | Ошибки различимы; неизвестный прогресс не показан как достоверный ноль; неуспешная отметка не считается сохранённой; повтор доступен |
| COURSE-15 | P1 | После успешного создания metadata вызвать отказ следующего шага сохранения; повторить сохранение. Отдельно потерять ответ самого POST создания | При известном public ID повтор продолжает тот же курс без дубликата. Если результат POST неизвестен, повторное создание блокируется с пояснением; нельзя автоматически создавать второй курс |
| COURSE-16 | P1 | Подготовить курс с элементами других типов либо повторяющимся уроком; открыть настройки, изменить metadata | Программа не перезаписывается упрощённой формой; чужие типы элементов сохраняются. В просмотре есть пояснение, что здесь доступны только уроки |

В `COURSE-07/08` проверять права конкретного курса по backend `canManage`, а не предполагать, что любой преподаватель школы управляет любым курсом. Назначение выбранных учеников не должно удалять действующие назначения вне редактируемого набора; включить их в подготовленные данные.

Создание заданий, тестов, оценок и иных типов элементов курса не имеет подключённого интерфейса и не является готовым флоу этого frontend.
