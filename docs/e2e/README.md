# Базовые e2e-флоу

Каталог описывает пользовательские пути текущего frontend: от регистрации до работы со школой, уроками, курсами, расписанием, материалами, чатами и звонками. Основа — [маршруты приложения](../../src/AppRoutes.tsx), подключённые к ним компоненты и хуки, endpoint-модули и существующие [Playwright-тесты](../../tests/e2e).

Это спецификация для написания и расширения тестов. Наличие сценария здесь не означает, что он автоматизирован или прошёл проверку. Текущее покрытие и ограничения приведены [отдельно](coverage.md). В рамках подготовки каталога браузерные тесты не запускались.

## Как читать сценарии

В каждой строке есть постоянный ID, подготовка данных, последовательность действий и проверяемый результат. Варианты через «для каждого» реализуются отдельными параметризованными тестами. Общие предусловия раздела применяются ко всем его строкам.

- **P0** — критичный путь: вход, доступ, создание основных сущностей, сохранность данных, доставка сообщений.
- **P1** — остальные базовые операции, ошибки, границы и восстановление.
- **Цель** — желаемое поведение, для которого в текущей реализации найден пробел. Его нельзя записывать как успешно работающую возможность.

Все проверки изменения серверных данных включают чтение после операции и проверку после перезагрузки. Для данных, доступных нескольким людям, результат также проверяется в независимом контексте второго пользователя. Для локального черновика урока проверяется именно сохранение на устройстве.

## Карта маршрутов

`S` — `schoolPublicId`, `C` — `coursePublicId`, `L` — `lessonId`, `R` — `requestPublicId`. Это обозначения в документации, а не буквальные сегменты URL.

| Маршрут | Назначение | Сценарии |
| --- | --- | --- |
| `/`, `/auth`, `/auth/login`, `/auth/register` | Вход и регистрация | AUTH-01–09, SESSION-01–09 |
| `/app` | Выбор активной школы или онбординг | NAV-01–03 |
| `/app/schools` | Мои школы | NAV-02–04 |
| `/app/profile`, `/profile` | Профиль и старый адрес | PROFILE-01–05, NAV-07 |
| `/app/schools/S` | Переход к «Сегодня» | NAV-01 |
| `/app/schools/S/today` | Главная страница школы | TODAY-01–05 |
| `/app/schools/S/lessons` | Список уроков | LESSON-01–06 |
| `/app/schools/S/lessons/L`, `?edit=true` | Просмотр и редактирование урока | LESSON-03, EDITOR-01–12 |
| `/app/schools/S/courses` | Каталог курсов | COURSE-01–04 |
| `/app/schools/S/courses/C` | Программа, ученики, прогресс | COURSE-05–16 |
| `/app/schools/S/courses/C/lessons/L` | Чтение урока в курсе | COURSE-09–10 |
| `/app/schools/S/schedule`, `?eventId=…` | Расписание и конкретное занятие | SCHEDULE-01–12 |
| `/app/schools/S/calls`, `?room=…&title=…` | Подключение к звонку | CALL-01–08 |
| `/app/schools/S/files` | Материалы | FILE-01–12 |
| `/app/schools/S/chats`, `?user=…` | Групповые и личные чаты | CHAT-01–12 |
| `/app/schools/S/students` | Ученики и приглашения | ACCESS-02, INV-01–06, NAV-09 |
| `/onboarding`, `?invite=…` | Подключение или заявка | ONB-01–03/11, INV-03–05, PROFILE-05 |
| `/onboarding/waiting/R` | Ожидание решения и игра | ONB-04–11, PROFILE-05 |
| `/developer` | Служебная работа с заявками | DEV-01–04 |
| `/admin`, `/admin/schools/S/*` | Старые адреса | NAV-07 |
| `/Lessons`, `/Lessons/L` | Старые адреса уроков | NAV-07 |
| `/403`, неизвестный путь | Ошибки доступа и 404 | NAV-08 |

В приложение не включаются флоу только по наличию старого компонента или endpoint-метода. Не подключённые к маршрутам экраны, папки уроков, настройки школы и совместная доска перечислены в [ограничениях](coverage.md).
