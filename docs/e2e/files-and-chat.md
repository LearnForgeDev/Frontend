# Материалы и чаты

Источники: [материалы](../../src/Services/Schools/FilesPage/FilesPage.tsx), [файловый API](../../src/Endpoints/files/files.endpoints.ts), [чаты школы](../../src/Services/Schools/ChatsPage/ChatsPage.tsx), [SignalR-сообщения](../../src/Services/Chat/hooks/useChatMessages/useChatMessages.ts), [выбор вложений](../../src/Services/Chat/components/FileSelectorModal/FileSelectorModal.tsx).

Предусловия: два участника школы A в независимых контекстах; посторонний пользователь школы B; общий чат; небольшие файлы с известными байтами. Для одинаковых имён хранить разные public ID и проверять именно нужный файл.

## Материалы

| ID | Приоритет | Подготовка и действия | Ожидаемый результат |
| --- | --- | --- | --- |
| FILE-01 | P0 | Открыть «Материалы» с файлами и отдельно пустую школу | Список соответствует backend текущей школы; видны имя, тип и размер; пустое состояние не маскирует ошибку |
| FILE-02 | P0 | Загрузить TXT через выбор файла; дождаться завершения pipeline; reload | Успешны presign, PUT байтов и complete; в списке и API один новый public ID, содержимое совпадает с оригиналом |
| FILE-03 | P1 | Выбрать несколько файлов, повторить drag-and-drop; включить один отказ загрузки среди успешных | Каждый файл имеет свой прогресс/результат; успешные доступны, неуспешный не выдаётся за готовый; сообщение сообщает реальное число результатов |
| FILE-04 | P1 | Замедлить тестовую загрузку, нажать отмену; затем загрузить тот же файл снова | Отменённая загрузка не завершается ложным успехом, показана отмена; повтор возможен и создаёт корректный файл |
| FILE-05 | P1 | Искать по части имени и другому регистру, менять фильтр формата, переключать сетку/список, очистить поиск | Состав результатов соответствует фильтру; режим отображения не меняет данные; для отсутствующего совпадения есть отдельное состояние |
| FILE-06 | P0 | Открыть предпросмотр TXT, PNG, PDF и неподдерживаемого формата; закрыть и открыть другой файл | Для поддерживаемых форматов показано именно выбранное содержимое; неподдерживаемый не выдаёт битый просмотр за успех; старое содержимое не появляется при переключении |
| FILE-07 | P0 | Нажать UI-скачивание файла с кириллицей/пробелами в имени | Получено событие download, имя и байты совпадают с оригиналом. API-чтение содержимого не заменяет эту проверку браузерной кнопки |
| FILE-08 | P0 | Открыть удаление, отменить; затем подтвердить и reload | Отмена оставляет файл; успех удаления убирает выбранный public ID из backend/списка; файл с таким же именем, но другим ID остаётся |
| FILE-09 | P1 | Вызвать ошибку списка и «Повторить», ошибку preview/download/delete | Видна понятная ошибка; нет ложного пустого списка или успешного удаления; после восстановления нужная операция доступна |
| FILE-10 | P0 | В двух школах загрузить разные файлы, переключить школу; посторонним запросить metadata и content чужого файла | Нет смешения списков/preview; backend отказывает чужому пользователю, прямой URL не обходит доступ |
| FILE-11 | P1 | На mobile нажать «Снять», передать тестовое изображение в capture-input | Загрузка проходит общий pipeline, новый файл доступен; реальная камера устройства проверяется отдельно от `setInputFiles` |
| FILE-12 | P1 | Загрузить два разных файла с одинаковым именем; открыть/скачать/удалить один; отдельно отменить системный выбор файла | Операции адресованы public ID, второй файл не затронут; отмена выбора не создаёт пустую загрузку |

Наборы ролей для загрузки/удаления определять реальным backend. В текущем UI «Материалов» нет такой же проверки canTeach, как у уроков; не записывать запрет для Student как уже существующий frontend-контракт.

## Чаты

| ID | Приоритет | Подготовка и действия | Ожидаемый результат |
| --- | --- | --- | --- |
| CHAT-01 | P0 | Открыть «Группы», выбрать общий чат; повторить пустой список и ошибку чтения | Показан список своей школы, открыта история выбранного чата; ошибка отличается от отсутствия сообщений |
| CHAT-02 | P0 | В группе отправить уникальное сообщение через Enter и отдельным тестом через кнопку; проверить во втором контексте, reload у обоих | Есть реальная доставка через SignalR и сохранённая история; сообщение одно, автор и время корректны; локальное эхо не заменяет проверку получателя |
| CHAT-03 | P1 | Попробовать отправить пустую строку и пробелы, затем обычный текст; повторить при disconnected/connecting | Пустой текст без вложений не отправляется; отправка и ввод недоступны до соединения; возвращение связи не создаёт случайных сообщений |
| CHAT-04 | P1 | Во вкладке «Группы» создать чат с названием/описанием; отдельно пустое имя, отмена и отказ backend | Успешный чат появляется после перечитывания; пустое имя не отправляется; отмена/ошибка не создаёт фиктивный чат. Права каждой роли проверяются по backend |
| CHAT-05 | P0 | В «Личные» нажать «Написать», выбрать участника по имени, отправить сообщение; затем повторно выбрать его | Открыт диалог нужного пользователя, сообщение получено и сохранено; в локальном списке нет дубликатов этого собеседника |
| CHAT-06 | P1 | Из строки ученика перейти через «Написать»; отдельно открыть `?user=…` для существующего/чужого участника | Открыт правильный direct-диалог; обработанный query-параметр очищен; чужой ID не даёт доступ к переписке/не создаёт ложного собеседника |
| CHAT-07 | P0 | Прикрепить существующий файл; отдельно загрузить новый из модального окна, убрать один chip, отправить только вложение | Выбраны реальные public ID; удалённое вложение не отправлено, повторный выбор не дублирует его; сообщение с файлом доступно получателю и после reload |
| CHAT-08 | P1 | В выборе файлов искать/фильтровать, выбрать несколько, отменить; отдельно прервать загрузку и закрыть диалог | Отмена не прикрепляет файлы, закрытие прерывает текущие загрузки; при повторном открытии нет старых выбранных chip; уже загруженный серверный файл не объявляется удалённым без API-удаления |
| CHAT-09 | P0 | Получить изображение и документ; открыть изображение и скачать документ | Авторизованный preview показывает правильную картинку; download возвращает исходные байты; посторонний не может получить вложение по прямому URL |
| CHAT-10 | P1 | Между двумя чатами отправить разные сообщения, быстро переключаться; отключить и восстановить сеть | История, авторы и вложения не перетекают между чатами; статус соединения отражает состояние; после восстановления доступна история без потери серверных сообщений |
| CHAT-11 | P0 | В группе и direct-чате нажать создание конференции, получить приглашение вторым пользователем, открыть его | Перед отправкой backend подтверждает комнату; сообщение содержит рабочую ссылку нужной школы и room; получатель попадает в тот же звонок. При отказе токена приглашение не считается созданным |
| CHAT-12 | P1 | На mobile открыть чат, вернуться к списку; если отображается плавающий виджет, открыть/закрыть его и перейти в другой раздел | История и поле ввода доступны, возврат к списку работает; виджет не перекрывает основные действия и не смешивает выбранную школу |

В коде есть отдельный `ChatInput` с ограничением `MESSAGE_MAX_LENGTH`, но подключённая страница `ChatsPage` содержит собственную форму без такого `maxLength` и без multiline. Проверки лимита 4000 и Shift+Enter как гарантированного переноса строки нельзя переносить на неё по одному совпадению названия компонента. Целевой лимит и единый контракт ввода нужно согласовать до добавления соответствующего положительного e2e.
