# Уроки и редактор

Источники: [список уроков](../../src/Services/Lessons/LessonsMainPage.tsx), [страница урока](../../src/Services/Lessons/LessonIdPage.tsx), [локальный черновик](../../src/Services/Lessons/hooks/useLessonEditor/useLessonEditor.ts), [сохранение](../../src/Services/Lessons/components/TextEditorComponents/plugins/ControlsPlugin.tsx), [панель редактора](../../src/Services/Lessons/components/TextEditorComponents/ui/Toolbar.tsx).

Предусловия: Owner/Teacher и Student одной школы; отдельные уроки для чтения, редактирования и удаления; desktop-контекст для редактирования. Загруженный с сервера урок содержит корректный Lexical-документ. Для mobile задавать и viewport, и соответствующий user agent/устройство: приложение использует определение устройства.

## Список и доступ

| ID | Приоритет | Подготовка и действия | Ожидаемый результат |
| --- | --- | --- | --- |
| LESSON-01 | P0 | Открыть «Уроки» каждой ролью; повторить в школе без уроков | Карточки соответствуют `/api/ApiLessons/S/all`; в пустой школе — «У вас пока нет уроков»; создание только у Owner/Teacher |
| LESSON-02 | P0 | Нажать «Создать урок», в том числе повторно во время запроса | Создан один урок в текущей школе, получен ID; открыт `/lessons/L?edit=true`; API чтения и reload подтверждают существование урока |
| LESSON-03 | P0 | Открыть карточку кликом и отдельно клавишей Enter; затем открыть прямую ссылку и reload | Открывается нужный ID; Owner/Teacher из списка получают режим редактирования, Student — просмотр. Прямая ссылка не зависит от router state для загрузки содержимого |
| LESSON-04 | P1 | Через «Опции урока» → «Удалить» открыть подтверждение; сначала отменить, затем подтвердить | Отмена сохраняет урок; подтверждение удаляет его на backend, карточка исчезает после reload; другой урок с похожим именем остаётся |
| LESSON-05 | P1 | Вызвать ошибку чтения списка и повторить; отдельно отказ создания/удаления | Чтение показывает ошибку и «Повторить»; не появляется несуществующий урок; неуспешное оптимистическое удаление возвращает карточку |
| LESSON-06 | P0 | Учеником открыть урок с `?edit=true`; отдельно запросить урок чужой школы или несуществующий ID | Ученик не получает toolbar/редактируемый текст/кнопку сохранения; backend не раскрывает чужой урок. Для отсутствующего урока ожидается явное состояние недоступности; текущую обработку нужно проверить отдельным тестом |

Список сейчас не подключает файловый менеджер с папками, поиском и сортировкой. «Переименовать» и «Переместить» в меню вызывают пустые обработчики. Успешные сценарии этих операций добавлять после реализации; наличие пункта меню не считать результатом.

## Работа с содержимым

Все варианты форматирования проверять по отдельности: ввести короткий текст, применить действие, проверить DOM/состояние редактора, сохранить локальный черновик и перечитать после reload. Не ограничиваться тем, что кнопка нажалась.

## Разделение локального и серверного результата

Создание урока на сервере и загрузка вложений работают через backend. Изменение документа и кнопка «Сохранить» сейчас сохраняют только локальный черновик. Новая сессия с пустым localStorage не обязана увидеть этот текст. Восстановление названия из metadata по прямой ссылке тоже нужно проверять: текущий заголовок берётся из router state, при его отсутствии используется «Урок».

Изоляцию черновиков между школами/аккаунтами проверять по COMMON-05. Текущий ключ черновика использует только `lessonId`, поэтому этот путь требует отдельного внимания и не считается гарантированно безопасным.
